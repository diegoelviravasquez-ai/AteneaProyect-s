# Atenea Documentación

Repositorio de documentación viva del proyecto **Atenea Digital**
(Égida + Mochuelos), la aplicación web de la Asociación de Altas
Capacidades de Salamanca (Atenea).

## Contenido

- `investigacion/` — Estudios, dictámenes jurídicos, análisis OSINT
  de fuentes de financiación.
- `propuestas/` — Documentos de propuesta a Junta Directiva,
  asambleas y patronos potenciales.
- `hojas-de-ruta/` — Documentos HTML interactivos para seguimiento
  del proyecto. Abrir con doble clic en cualquier navegador.
- `subvenciones/` — Memorias técnicas, presupuestos y documentación
  de cada convocatoria presentada.
- `identidad/` — Briefs visuales, ilustraciones, logotipos,
  paleta cromática.

## Sobre el código fuente

El código fuente de la aplicación vive en un repositorio separado
(`atenea-digital`). Este repositorio contiene solo documentación
institucional, propuestas y materiales de gestión.

## Confidencialidad

Repositorio privado. Contiene datos institucionales de Atenea
(NIF, dirección, contactos) y documentación interna. No compartir
enlaces ni archivos fuera del equipo autorizado.
